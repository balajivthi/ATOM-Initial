# Quiz: The ServiceNow Interface

Answer these questions about navigating the platform. Your score is saved, and reasoning is revealed after you submit.

1. Which navigation shortcut opens the Incident table's list view?
   A. incident.form
   B. incident.list
   C. incident.view
   D. incident.module
   CORRECT: B
   EXPLAIN: Typing `incident.list` in the filter navigator opens the list view of the Incident table.

2. Which shortcut opens a NEW (blank) incident record form?
   A. incident.list
   B. incident.new
   C. incident.form
   D. incident.create
   CORRECT: C
   EXPLAIN: `incident.form` opens a new, empty record form for the table.

3. How do you open a list in a NEW browser tab?
   A. Type `incident.list` in capital letters: `incident.LIST`
   B. Hold Shift while pressing Enter
   C. Right-click the All menu
   D. Append `/new` to the URL
   CORRECT: A
   EXPLAIN: Appending `.LIST` in capital letters opens the list in a new browser tab; `.FORM` does the same for a new-record form.

4. Where do the platform's applications and modules appear?
   A. Only in the footer
   B. In the All menu / filter navigator
   C. Only in browser bookmarks
   D. On the login screen
   CORRECT: B
   EXPLAIN: The All menu opens the filter navigator — the tree of every application and module you can access.

5. Why create an update set early during your labs?
   A. It speeds up the browser
   B. It captures your configuration so it can be reviewed and moved later
   C. It is required to log in
   D. It creates new users automatically
   CORRECT: B
   EXPLAIN: While an update set is "current", all your configuration is captured for review, export and reuse on other instances.
