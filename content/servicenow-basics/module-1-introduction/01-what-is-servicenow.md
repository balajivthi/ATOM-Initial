# What is ServiceNow?

ServiceNow is a **cloud-based platform-as-a-service (PaaS)** that automates enterprise workflows — from IT service management (ITSM) to HR, customer service, security, and beyond. Companies use it as a single **system of record** for how work gets done.

## Why ServiceNow Matters

ServiceNow started in 2004 as an IT help-desk tool, but it has grown into the **Now Platform**, a "platform of platforms" that powers digital workflows across an entire organisation. Every day, tens of thousands of organisations run everything from password resets to full employee onboarding on it.

### Key Characteristics

| Characteristic | What it means |
| --- | --- |
| **Single system of record** | One shared source of truth for incidents, requests, changes, problems and more |
| **Automation** | Repetitive tasks (password resets, approvals, assignments) run automatically |
| **Cloud-based** | Accessible from anywhere; ServiceNow manages the underlying infrastructure |
| **Multi-applications** | ITSM, ITOM, HRSD, CSM, SecOps, ITBM and custom apps all live on one platform |
| **Configurable, low-code** | Admins build most functionality by configuration, not custom code |
| **Extensible** | Scripting, REST APIs, Flow Designer and AI Agents extend the platform further |

## What Runs on the Platform?

| Product family | Purpose |
| --- | --- |
| **ITSM** (IT Service Management) | Incidents, requests, problems, changes, service catalogue |
| **ITOM** (IT Operations Management) | Discovery, service mapping, cloud orchestration |
| **HRSD** (HR Service Delivery) | Employee onboarding, HR cases and requests |
| **CSM** (Customer Service Management) | Customer cases, portals, self-service |
| **SecOps** | Security incidents, vulnerability response |
| **ITBM** (Strategic Portfolio Management) | Projects, demand, resource planning |

## The Business Value

- **Speed**: workflows that once took days (onboarding, access requests) complete in minutes.
- **Consistency**: every request follows the same governed process, reducing human error.
- **Visibility**: dashboards and performance analytics show exactly where work sits.
- **Self-service**: portals and virtual agents deflect routine tickets away from human agents.

## Getting a Practice Instance

ServiceNow offers free **Personal Developer Instances (PDIs)** so you can learn and build safely:

1. Sign up at [developer.servicenow.com](https://developer.servicenow.com).
2. Click **Request Instance** and choose a release (a "family" such as the current release).
3. Your instance URL looks like `https://dev12345.service-now.com` — log in with your developer credentials.

> **Up to date note:** ServiceNow releases major platform versions roughly twice a year (named alphabetically, e.g. Washington DC, Xanadu, Yokohama, Zurich). Most modern training instances run the **Next Experience UI**, which we explore in the next module.
