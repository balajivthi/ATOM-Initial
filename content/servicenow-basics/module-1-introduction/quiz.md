# Quiz: Introduction to ServiceNow

Answer these questions to check your understanding of Module 1. Your score is saved, and reasoning is revealed after you submit.

1. What type of platform is ServiceNow?
   A. IaaS (Infrastructure as a Service)
   B. PaaS (Platform as a Service)
   C. A standalone database product
   D. A desktop application
   CORRECT: B
   EXPLAIN: ServiceNow is a cloud-based platform-as-a-service — you build on top of it rather than manage the infrastructure yourself.

2. What does "single system of record" mean in ServiceNow?
   A. Only one user can view records at a time
   B. Every record exists in exactly one place and is shared across the platform
   C. Records are stored only in Excel files
   D. Each application has its own private database
   CORRECT: B
   EXPLAIN: One shared source of truth means incidents, requests and changes live in one place that every application can reference.

3. Which of these is NOT a ServiceNow product family?
   A. ITSM (IT Service Management)
   B. ITOM (IT Operations Management)
   C. HRSD (HR Service Delivery)
   D. Graphic design software
   CORRECT: D
   EXPLAIN: ITSM, ITOM and HRSD are all ServiceNow applications; graphic design software is not.

4. What is the core mental model behind the Now Platform?
   A. Everything is a compiled program
   B. Everything is data on tables, wrapped in configured forms, lists and workflows
   C. Everything runs in a web browser extension
   D. Everything must be coded in Java
   CORRECT: B
   EXPLAIN: Tables store records, and forms, lists and workflows are configuration layers on top. Most platform behaviour is configuration, not compiled code.

5. Where do you get a free instance to practise?
   A. docs.servicenow.com
   B. developer.servicenow.com
   C. store.servicenow.com
   D. community.servicenow.com
   CORRECT: B
   EXPLAIN: ServiceNow offers free Personal Developer Instances (PDIs) at developer.servicenow.com.
