# Quiz: Working with Lists & Forms

Answer these questions about lists and forms. Your score is saved, and reasoning is revealed after you submit.

1. Which filter operator resolves to the user who is viewing the list at that moment?
   A. is
   B. is not
   C. is (dynamic)
   D. starts with
   CORRECT: C
   EXPLAIN: `is (dynamic)` resolves values like "Me" at runtime, so each user automatically sees their own records.

2. How do you share a saved filter with every user on the platform?
   A. Save the filter and choose "Everyone"
   B. Email the filter URL to all users
   C. Add the filter to a group
   D. Select "Only me" and hope others find it
   CORRECT: A
   EXPLAIN: When saving a filter, choosing "Everyone" makes it visible to all users; it is then managed under List Controls → Filters.

3. Where do you manage saved filters for a list?
   A. The banner frame
   B. List Controls → Filters
   C. The user menu
   D. System Logs
   CORRECT: B
   EXPLAIN: List Controls (the wrench icon) holds the list's filters, columns and export options.

4. Which tool lets an admin reorder fields directly on a form?
   A. List Layout
   B. Configure → Form Design (or Configure Form Layout)
   C. The All menu
   D. A browser extension
   CORRECT: B
   EXPLAIN: Form Design is the newer visual editor; Configure Form Layout is the classic two-pane editor. Both reorder form fields without scripting.

5. What do the red asterisk fields on a form indicate?
   A. The field is hidden
   B. The field is mandatory
   C. The field is broken
   D. The field is read-only
   CORRECT: B
   EXPLAIN: Mandatory fields are marked with a red asterisk — the record cannot be saved until they are filled.
